# 📘 Шпаргалка по Go (аналог Java SE)

Отличная идея! Go сильно отличается от Java по философии, поэтому структура будет немного другой. Ниже — полный список тем по Go, адаптированный под ваш Java-бэкграунд.

---

## 1. [[Основы языка Go]]

- Go toolchain: `go build`, `go run`, `go mod`, `go vet`, `go fmt`, `go test`
- Пакеты: `package main`, `import`, `go.mod`, `go.sum`
- Типы данных: `int`, `float64`, `bool`, `string`, `byte`, `rune`
- Zero values (нулевые значения для каждого типа)
- Объявление переменных: `var`, `:=`, type inference
- Операторы, управляющие конструкции (`if`, `switch`, `for` — единственный цикл)
- Массивы vs Слайсы (фундаментальное отличие!)
- Строки: неизменяемость, UTF-8, `[]byte`, пакет `strings`

## 2. [[ООП в Go (Structs & Interfaces)]]

- Структуры (`struct`), поля, инициализация
- Методы: value receiver vs pointer receiver
- Композиция вместо наследования (embedding)
- Интерфейсы: **неявная** реализация (duck typing)
- Пустой интерфейс `any` (`interface{}`)
- Нет классов, нет наследования, нет `abstract`, нет `static`
- Method sets (набор методов типа)
- Type assertions (`x.(T)`), type switches
- Enums через `iota`
- `new()` vs `&T{}`

## 3. [[Generics (Go 1.18+)]]

- Type parameters: `func[T any](x T)`
- Type constraints: `comparable`, `any`, кастомные constraints
- Type inference с дженериками
- Ограничения: нет ковариантности/контравариантности как в Java

## 4. [[Обработка ошибок]]

- Интерфейс `error`: `Error() string`
- Паттерн `if err != nil`
- Обёртывание ошибок: `fmt.Errorf`, `%w`
- `errors.Is`, `errors.As`
- Кастомные типы ошибок
- `panic` / `recover` (аналог unchecked exceptions, но для критических случаев)
- `defer` для гарантированного освобождения ресурсов (аналог `finally`)

## 5. [[Встроенные структуры данных]]

- **Slices**: внутреннее устройство (pointer, len, cap), `append`, `copy`, slicing, `make`
- **Maps**: внутреннее устройство, итерация (случайный порядок), nil map vs empty map
- **Channels**: buffered / unbuffered, направление (`<-chan`, `chan<-`)
- Пакет `sort`: `sort.Slice`, `sort.SliceStable`
- `container/list`, `container/heap` (редко используются)

## 6. [[Функциональное программирование Go]]

- Функции как first-class citizens
- Замыкания (closures) и захват переменных
- Higher-order functions (функции принимают/возвращают функции)
- Function types: `type Handler func(http.ResponseWriter, *http.Request)`
- `defer`: стек вызовов, порядок выполнения
- Нет Stream API, но есть ручные паттерны: map, filter, reduce
- Нет `Optional` (используются указатели, множественные return, или `sql.NullString`)

## 7. [[Конкурентность (Concurrency)]] 

- Goroutines vs OS threads (стек 2-8 KB, M:N scheduler)
- Channels: send, receive, close, `range` over channel
- `select`: мультиплексирование каналов
- `sync.WaitGroup`: ожидание группы горутин
- `sync.Mutex`, `sync.RWMutex`
- `sync.Once`: ленивая инициализация
- `sync.Pool`: переиспользование объектов
- `context.Context`: cancellation, timeouts, values
- Паттерны: worker pool, fan-in, fan-out, pipeline, semaphore
- Data races: `go run -race`, `go test -race`
- `sync/atomic`: атомарные операции

## 8. [[Память и GC]]

- Stack vs Heap, **escape analysis** (как Go решает, где аллоцировать)
- Garbage Collector: tri-color algorithm, concurrent GC
- Указатели: `*T`, `nil`, нет арифметики указателей (в отличие от C)
- Memory alignment, struct padding
- `runtime.GC()`, `runtime.ReadMemStats`
- Нет `equals` / `hashCode`: `==` для comparable типов, `reflect.DeepEqual` для глубокого сравнения

## 9. [[I/O]]

- Интерфейсы `io.Reader`, `io.Writer` (ключевая абстракция Go)
- Пакет `os`: файлы, переменные окружения
- `bufio`: буферизированный I/O
- `encoding/json`: `Marshal` / `Unmarshal`, struct tags
- `net/http`: клиент и сервер
- `database/sql`: пул соединений, транзакции, `sql.Scanner`

## 10. [[Рефлексия и теги]]

- Пакет `reflect`: `reflect.Type`, `reflect.Value`
- Struct tags: `json:"name"`, `db:"id"`, `yaml:"field"`
- Когда использовать / избегать рефлексию
- Нет аннотаций как в Java (теги — ближайший аналог)

## 11. [[Новые фичи (Go 1.18–1.23)]]

- Generics (1.18)
- `any` как алиас для `interface{}` (1.18)
- Пакеты `slices` и `maps` (1.21)
- Встроенные `min` / `max` (1.21)
- Range over integers: `for i := range 10` (1.22)
- Улучшенный роутинг в `net/http`: методы, wildcard в путях (1.22)
- Range over functions / iterators (1.23)

# 📗 Экосистема Go (аналог Spring)

Раз вы упомянули Spring, вот как это мапится на Go-экосистему:

## 12. [[HTTP и Web-фреймворки]]

- Стандартная библиотека `net/http` (аналог Servlets)
- Роутеры: `chi` (лёгкий), `gin` (популярный), `echo`
- Middleware: логирование, auth, CORS, recovery

## 13. [[Dependency Injection Go]]

- Ручной DI (просто передаёте зависимости через конструкторы)
- `google/wire` (compile-time DI, аналог Spring DI)
- `uber-go/fx` (runtime DI)

## 14. [[Работа с БД]]

- `database/sql` (стандарт, низкоуровневый)
- `sqlx` (расширение `database/sql`, Named queries)
- `gorm` (ORM, аналог Hibernate, но легче)
- `ent` (ORM от Meta/Facebook, code generation)
- Миграции: `golang-migrate`, `goose`

## 15. [[Конфигурация и логирование]]

- Конфиги: `viper` (аналог Spring Config)
- Логирование: `slog` (стандарт с 1.21), `zap`, `zerolog`
- Переменные окружения: `os.Getenv`, `godotenv`

## 16. [[Тестирование]]

- Пакет `testing`: `TestXxx`, `BenchmarkXxx`, `ExampleXxx`
- Table-driven tests (идиоматика Go)
- `testify`: assertions, mocks
- `httptest`: тестирование HTTP-хэндлеров
- Coverage: `go test -cover`

## 17. [[Микросервисы и gRPC]]

- gRPC + Protocol Buffers (основной способ общения микросервисов в Go)
- `google.golang.org/grpc`
- Service discovery, health checks
- Kafka клиенты: `segmentio/kafka-go`, `confluent-kafka-go`

## 18. [[Деплой и инструменты]]

- `Dockerfile` для Go (multi-stage builds)
- Линтеры: `golangci-lint`
- Профилирование: `pprof` (CPU, memory, goroutines)
- `Makefile` / `Taskfile`
